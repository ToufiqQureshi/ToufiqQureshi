## 🏗️ Featured Project

### Staybooker — Multi-Tenant Hotel Booking SaaS
Solo-designed and built AI-powered SaaS platform, ~74,000 lines of code, live payments in production.

| Category | Details |
|----------|---------|
| 🔌 **Backend** | 195+ REST API endpoints · FastAPI · Supabase (PostgreSQL) |
| 🗄️ **Data Layer** | 144 data models · SQLModel · Redis caching with automatic fallback |
| 🤖 **AI Agents** | Multi-agent layer on Agno + Groq LLMs — router agent delegates queries to specialist agents (finance, booking, operations, general), plus a guest concierge bot and WhatsApp sales agent |
| 💳 **Payments** | Razorpay integration with HMAC-SHA256 webhook verification and server-side amount validation |
| 🎨 **Frontend** | React 18 + TypeScript + TanStack Query · shadcn/ui · Recharts · deployed on Cloudflare Pages |
| 🔐 **Security** | JWT auth · OWNER/MANAGER/STAFF RBAC · strict multi-tenant data isolation |
| 🧪 **Testing** | 56 pytest suites, 570+ passing tests · CI via GitHub Actions |
| 📡 **Integrations** | WhatsApp Business API · STAAH Channel Manager · Google Reviews API · real-time updates via SSE |
